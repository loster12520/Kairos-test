## 3. 与计划的偏离

| # | 计划 | 实际 | 理由 |

| 1 | 计划未提层序 | merge 首版按字母排序层，override 排到了 base 前 | 级联语义错误；改为按 layerIndex，并新增 A9 守护 |

## 4. 影响后续轮次的问题

1. 剪枝以"产物里出现的类名"为使用集合，对**运行时拼出来的类名**无能为力；当前折叠保证类名是字面量，一旦出现动态拼接就会误删。这条必须写进限制。
2. 跨模块镜像：feature 模块的样式在 demo 的 JS 里也会被内联一份（Kotlin/JS 链接），两边的映射一致，但**编译时间**随模块数增长。
3. 合并工具目前读文件路径，构建里由 Gradle 传参；若要做增量，需要先解决"模块产物何时失效"的问题（P1 报告里已记）。

## 补记（独立审查后的修正，2026-10-29）

三路独立审查（插件 / 运行时与 CLI / 构建与文档）都给了 FAIL，指出的是真实缺陷。修正如下：

| 级别 | 问题 | 处理 |
|---|---|---|
| 高 | 不可解析的样式块原先静默降级，运行时会产出**没有任何 CSS 规则**的类名 | 改为编译期硬错误，并补负向验证 |
| 高 | 全常量出口重算类名而非使用收集器返回的名字 | 改为全程使用 register 的返回值 |
| 高 | 同层同属性冲突的运行时兜底与编译期语义不一致 | 改为**编译期硬错误**；相同值静默保留一份 |
| 高 | dev 类名与 JVM 无插件渲染路径冲突，整个站点错位 | 撤除 dev 类名，需求由映射 + CLI 承接 |
| 高 | 验收脚本 A3 双计数、B7 恒真 | A3 改为独立 skip 通道；B7 改为捕获脚本错误并断言 folds=0 |
| 高 | 产物目录的 outputs.dir 修复无法被验证（都带 `--rerun-tasks`） | 新增 A11：删产物目录后用**普通构建**验证自动重建 |
| 中 | 陈旧产物、插件 jar 混入 kotlin-stdlib、prune 静默空转、why 缺源静默、merge 不校验 | 全部修正；插件 jar 从约 1 MB 降到 86 KB |
| 中 | 条件分支只做部分物化、常量分支选择不严谨、var 被当常量、Int.plus 被当字符串拼接 | 分别改为：非 Lit 且非不可达即报错、前置条件全静态 false 才取分支、只读 final 字段、按接收者类型判定 |
| 中 | 递归深度、控制字符转义、写盘原子性与失败传播 | 全部修正 |

修正后：clean 构建 0 错误，`node tools/verify.mjs --rebuild` **12/12**，`node tools/browser-check.mjs` **7/7**。
