# Code of Conduct

Be decent.

- Critique code and ideas, not people.
- Assume good intent; ask before assuming the worst reading of a message.
- Keep discussions on topic; moving a thread to a different venue is fine and sometimes better.
- Harassment, personal attacks, and discrimination are not welcome here.

Maintainers may edit or remove comments and close threads that ignore these rules. Serious or
repeated violations lead to a ban from the project spaces.
