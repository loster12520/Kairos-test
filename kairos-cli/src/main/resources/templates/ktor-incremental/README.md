# Kairos starter (incremental Ktor)

Generated by `kairos init`. This is the "add Kairos to an existing Ktor app" shape: one plain
Ktor route keeps rendering its own HTML, one new route is rendered by Kairos.

```bash
gradle run
# http://127.0.0.1:8080/         plain Ktor HTML (untouched)
# http://127.0.0.1:8080/pricing  Kairos page
```

What changed compared to the existing app:

1. `plugins { id("dev.kairos") }` and `implementation("dev.kairos:kairos-core")` /
   `kairos-htmx` in `build.gradle.kts`;
2. the new route returns `page(...)` instead of hand written HTML;
3. the compiled stylesheet is served from `build/kairos/jvm/main/kairos.css`.

No existing route, template or CSS file has to change.
