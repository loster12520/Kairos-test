# Kairos starter (static)

Generated by `kairos init`.

```bash
gradle run          # renders build/site/index.html
gradle assembleSite # copies kairos.css and kairos.map.json next to the page
```

The stylesheet is produced by the `dev.kairos` compiler plugin at
`build/kairos/jvm/main/kairos.css`; there is no CSS file to write by hand.
